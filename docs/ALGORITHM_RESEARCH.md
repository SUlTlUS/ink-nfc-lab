# 算法调研与离线对照 · 2026-10-17

## 结论

已实现七个可独立切换的算法。经典 0.4 与实验 v1 的实现不改，经典仍是默认；新增柔和 FS、Sierra Lite、Stucki、Bayer 8×8、无抖动五个候选。当前不能宣称已经找到实屏“最佳算法”，因为手机离线，且软件 RGB 指标无法覆盖真实纸面颜色、反射率与人眼观感。

本轮优先实屏对照 **Sierra Lite 与 Stucki**，保留经典和柔和 FS 作参照；海报文字另看无抖动。Bayer 可以产生规律网点，但本次人像预览明显更海报化，不建议直接取代照片默认。实验 v1 在部分灰阶较有对比感，不代表细节更准确。

## 方法与依据

Oklab 作为感知色差坐标的依据来自[作者的原始说明](https://bottosson.github.io/posts/oklab/)。经典算法固定保留，其余实验延续同一四色与平滑冷色策略，以便主要比较扩散/网点方式。

[Tanner Helland 的算法及原作者实现说明](https://tannerhelland.com/2012/12/28/dithering-eleven-algorithms-source-code.html)给出了 FS、Atkinson、Sierra、Stucki 和 Bayer 的扩散/有序网点思路。本项目自行实现数学核，使用蛇形扫描；有限色板选色、冷色去色权重与抖动强度也会影响结果，不能仅凭算法名字判断优劣。

| ID | 实现 | 本轮观察/用途 |
|---|---|---|
| 0 | 经典 0.4 / 原 FS | 已有实屏成功图，源码 SHA-256 与四个输出指纹固定 |
| 1 | 实验 v1 / Atkinson | 部分误差不传播，可能增加对比，但也可能丢失浅暗层次 |
| 2 | 平滑冷色 + FS | 保守的照片对照，完整扩散但保留较明显纹理 |
| 3 | Sierra Lite | 本轮人像、肤色合成图的低频误差较低，值得实屏先测 |
| 4 | Stucki | 更宽的扩散邻域，预览中细点较均匀，耗时略高 |
| 5 | Bayer 8×8 | 无前向误差状态，稳定规则纹理；人像出现明显色阶/网点风格 |
| 6 | 无抖动 | 纯色边缘干净，文字/海报候选，连续照片会丢失灰阶 |

## 现在的测试图够不够

**不能只靠原来的测试图选照片算法。** 它足以发现传输缺块、色码错误、灰阶纹理、小字丢失，但没有真实肤色、头发、衣物、复杂边缘、逆光或自然场景。

固定保留原图，并建立五类输入：

1. 原灰阶/色块/文字图：每次都跑的回归基线。
2. 真实人像：NASA 公共领域 astronaut，包含肤色、头发、衣物与高反差。来源和许可见 `testdata/README.md`，不得把单个人像当作所有照片的代表。
3. 程序生成文字/细线：8–40px 字号、中文、1–5px 线条、反白字。
4. 程序生成肤色/中性梯度：不是实测色卡，只用于查灰阶误染和肤色断层。
5. 程序生成暗部/纹理/天空：合成压力图，不冒充真实风景。

后续至少增加用户授权的逆光人像、自然风景、宠物和实际常用图片；不需要读取手机相册中的私人照片来完成本轮测试。

## 批量结果与局限

一次生成 **5 × 7 = 35 张** 全尺寸输出、5 张对照总览、HTML 图库和 CSV：

```sh
bash tools/algorithm-lab.sh
```

入口为 `build/algorithm-lab/index.html`，原始输入在 `sources/`，算法输出在 `outputs/`。总览为了避免半尺寸取样制造假条纹使用双线性缩小；检查真实像素请打开 552×768 输出，不依据缩略图判断网点。

相同输入、照片模式、亮度/对比度 0、强度 0.85，无抖动候选忽略强度。所有颜色仍为四个原始码。8×8 块均值 RGB RMSE 是低频保真代理，不是色度测量，也不是 SSIM 或实屏主观分数。单次 Mac 耗时含 JIT/GC 影响，不用于手机性能排行。

| 输入 | 经典块误差 | Sierra Lite | Stucki | 备注 |
|---|---:|---:|---:|---|
| 原测试图 | 35.94 | 35.94 | 36.60 | 基本相当，不支持更换默认 |
| 真实人像 | 29.08 | 23.54 | 25.81 | 低频数值改善不等于肤色一定更好 |
| 文字细线 | 1.37 | 1.32 | 1.50 | 差异小，应重点看小字笔画与边缘 |
| 合成肤色/中性 | 50.26 | 42.26 | 45.66 | 需实屏验证是否更自然 |
| 合成暗部纹理 | 55.58 | 40.80 | 45.97 | Bayer 为 40.11，但网点风格不同 |

本轮全部候选在严格中性区域未使用红黄色码。不能从这项指标推导出色偏已被物理校准。现有实拍的黄偏橙、黑偏灰，不应用相机白平衡不明的单张照片直接拟合新色板。

## 实屏验收方案

- 固定同一块板、同一图片、同一构图与亮度/对比度；只切算法，不混改参数。
- 固定耦合位置，只有 DE `009000` 后才记作有效样本，`68CA` 供电失败样本不能用于评判算法。
- 固定照明、观看距离；最好拍摄锁定曝光/白平衡的对照，分别看文字清晰度、肤色、暗部、网点纹理及红黄表现。
- 先测经典 / Sierra Lite / Stucki 三组，再按结果扩展；不要自动连续刷写未确认的板子或无休止重放 D4。
- 保持经典默认，直到用户实屏偏好和稳定性均有证据支持改变。
