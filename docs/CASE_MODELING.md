# NFC 墨水屏手机壳建模协作

目标是为华为 3.98 英寸、552×768 四色 NFC 墨水屏及原厂驱动板，制作可修改、可打印、可验证 NFC 耦合的手机壳。当前没有经过卡尺复核的完整机械尺寸，也没有公认的成品 3D 文件；这里是协作任务，不是打印说明书。

## 希望一起解决

1. **测量与版本区分**：记录手机型号/地区版本、壳体尺寸、屏幕可视区和外形、原厂驱动板/线圈、FPC 走向和接口位置。A0/A1、大小线圈等差异要分别标注，不假设通用。
2. **参数化壳体**：预留摄像头、按键、充电口和天线区域；屏幕与板子应可拆装，避免 FPC 急弯、线圈受压或屏幕受扭。优先提供 STEP 加可编辑源文件，不只给 STL。
3. **NFC 耦合测试**：线圈位置应可微调，留出不同机型的对位余量；以实际稳定寻卡和完整刷屏为准。不要把“线圈越大越好”或“射频功率拉满”写成未经测量的设计前提。
4. **试打印与反馈**：提交材料、打印方向、尺寸公差、试装照片（先去除个人信息）和实测手机/板子组合；区分原型、可用版本与未验证版本。

## 参与方式

在 [建模协作 Issue #1](https://github.com/wiwiwei/ink-nfc-lab/issues/1) 留言，写明可提供的测量、建模或试打印环节。也欢迎先只贡献卡尺尺寸、线圈定位方法或壳体约束。不要上传支付卡信息、设备序列号、原始 NFC 日志或含个人信息的照片。
