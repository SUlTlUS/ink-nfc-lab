# Ink NFC Lab 0.5.1 · NFC 控制器分流实验版

本版将手机 NFC 后端按可取得的控制器证据分流，并公开目前对 ST、NXP、THN31 等路线的证据与局限。**只有小米 17 / ST54L / Root 刷屏路径有本项目真机完整验证；NXP 刷屏尚未在本项目真机验证。**

## 更新

- 首页显示 ST、NXP 或“未能可靠识别”；不把品牌、SoC 或系统中残留的配置文件当作芯片实读。未知机型可手动尝试 NXP 实验路线。
- NXP 增加 QTag/Q-Poll Shell 后端，提供电脑 ADB Shell 和 App 内 Root 两种启动方式；只有发现 ISO-DEP、D1 校验、图像包和刷新状态通过后才逐步报告结果。ADB 方式需要电脑终端，当前没有集成 Shizuku。
- ST 沿用已验证的小米 17 Root 后端；未适配的 ST 机型不会自动套用底层补丁。无 Root 用户可从 App 打开电脑 PN532/PCR532 项目。
- README 与调研文档补充小米 17 的 ADB Shell/MIFARE 阻塞、NXP 与 ST 命令差异、其他 NFC 厂商线索，并发起手机壳 3D 建模协作。

## 安装与安全边界

附件是本地调试密钥签名的 APK。已核对签名证书：**本版与 v0.5.0 Release APK 不同，不能直接覆盖安装。** 若系统提示签名冲突，不要误以为 NFC 功能故障；卸载旧版会清除其 App 私有数据，先自行确认是否需要备份。刷图会覆盖当前屏幕；实验私有 NFC 后端可能造成 NFC 暂时不可用，若出现 `RESTORE_ERROR`，请关闭再开启手机 NFC。不要在依赖手机支付或门禁的场景测试。
