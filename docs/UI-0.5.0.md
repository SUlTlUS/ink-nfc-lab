# 0.5.0 精简界面

这是已实现并编译到 APK 的原生 Android 布局说明，不是真机新截图。手机已被用户带走，本次无法执行新的屏幕交互验收。

```text
INK STUDIO / NFC                           ⋯

┌ 预览 ─────────────────────────────────────┐
│ 算法名称 / 与发送数据一致                  │
│                                           │
│              画面预览                     │
│                                           │
│ 简短图像信息                              │
│ [选择图片]                                │
│ [画面设置 · 算法 / 构图 / 调色]            │
└───────────────────────────────────────────┘
状态 / 必要错误说明 / 进度

[选择图片或刷入这幅画面]        [停止，仅会话中]
```

画面设置默认收起，展开后才显示七种算法、照片/插画/黑白预设、抖动、构图、旋转、原图对照、亮度和对比度。经典仍为启动默认，恢复默认参数也回到经典。

右上角 `⋯` 是唯一底层调试入口，含设备支持信息/导出、自动或标准连接方式、Root 诊断、7A 探测、APC、普通寻卡、恢复和日志导出。主页面没有 Root、MIFARE、NCI 或 APC 的常驻大块说明；出现与用户操作有关的错误时仍明确显示原因。

标准 NFC 会话不请求 Root。未支持的机型禁用私有命令按钮；待恢复快照未清理前禁止切换连接方式或开启标准会话，避免掩盖上次恢复失败。

## 回连后的交互验收清单

- 未选图时底部按钮打开选图器；有预览后才出现覆盖确认，确认中标明算法与连接路径。
- 右上角能开关调试面板，主页面不会因日志更新自动跳动。
- 七种算法能在同图、同参数间切换；快速连续调节后只显示最后一代结果。
- 上传时编辑与连接方式不可改，停止会关闭链接；刷新阶段不是上传100%完成，只有009000才显示成功。
- 小米17自动后端仍需真实Root会话回归；其他手机标准后端需至少完成发现/ISO-DEP/D1/最终刷新四级验证。
- 检查不同屏幕、字体大小、系统状态栏/导航栏的安全区。构建成功不替代这些交互测试。
